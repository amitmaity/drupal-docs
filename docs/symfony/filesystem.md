# Filesystem

The **Filesystem** component provides portable file and directory operations: copy, move, remove, mkdir, and symlink. Drupal's `file_system` service wraps Symfony Filesystem with stream wrapper awareness.

## Core concepts

```php
<?php

declare(strict_types=1);

use Symfony\Component\Filesystem\Filesystem;

$fs = new Filesystem();
$fs->mkdir('/tmp/my-dir');
$fs->copy('/source/file.txt', '/dest/file.txt');
$fs->remove('/tmp/my-dir');
```

| Method | Purpose |
|--------|---------|
| `mkdir()` | Create directories recursively |
| `copy()` | Copy files |
| `rename()` / `mirror()` | Move or sync directories |
| `remove()` | Delete files or trees |
| `exists()` | Check path exists |

## How Drupal uses Filesystem

### The `file_system` service

`Drupal\Core\File\FileSystem` implements `FileSystemInterface` and understands Drupal stream wrappers (`public://`, `private://`, `temporary://`):

```php
<?php

declare(strict_types=1);

/** @var \Drupal\Core\File\FileSystemInterface $fileSystem */
$fileSystem = \Drupal::service('file_system');

$realPath = $fileSystem->realpath('public://documents/report.pdf');
$directory = $fileSystem->prepareDirectory('public://documents', FileSystemInterface::CREATE_DIRECTORY | FileSystemInterface::MODIFY_PERMISSIONS);
```

### File API vs raw filesystem

For managed files (with `file_managed` table entries), use the File entity API. Use `file_system` for low-level path operations.

```php
<?php

declare(strict_types=1);

use Drupal\file\Entity\File;

$file = File::create([
  'uri' => 'public://uploads/photo.jpg',
  'status' => 1,
]);
$file->save();
```

## Stream wrappers

| Scheme | Maps to |
|--------|---------|
| `public://` | `sites/default/files` |
| `private://` | Outside webroot (configured) |
| `temporary://` | OS temp or configured path |

```php
<?php

declare(strict_types=1);

$uri = 'public://exports/products-' . date('Y-m-d') . '.csv';
$path = \Drupal::service('file_system')->realpath(dirname($uri));
```

## Custom module example: export archive service

=== "Service"

    ```php
    <?php

    declare(strict_types=1);

    namespace Drupal\my_module\Service;

    use Drupal\Core\File\FileSystemInterface;
    use Symfony\Component\Filesystem\Filesystem;

    final class ProductArchiveService {

      private readonly Filesystem $filesystem;

      public function __construct(
        private readonly FileSystemInterface $fileSystem,
      ) {
        $this->filesystem = new Filesystem();
      }

      public function exportToDirectory(array $productFiles, string $destinationUri): string {
        $destDir = $this->fileSystem->realpath($destinationUri)
          ?: $this->fileSystem->dirname($destinationUri);

        $this->fileSystem->prepareDirectory(
          $destinationUri,
          FileSystemInterface::CREATE_DIRECTORY | FileSystemInterface::MODIFY_PERMISSIONS,
        );

        $stagingDir = $this->fileSystem->tempnam('temporary://', 'export_');
        $this->filesystem->remove($stagingDir);
        $this->filesystem->mkdir($stagingDir);

        foreach ($productFiles as $filename => $content) {
          $stagingPath = $stagingDir . '/' . $filename;
          file_put_contents($stagingPath, $content);
        }

        $zipPath = $destDir . '/products-export.zip';
        $this->createZip($stagingDir, $zipPath);
        $this->filesystem->remove($stagingDir);

        return $zipPath;
      }

      private function createZip(string $sourceDir, string $zipPath): void {
        $zip = new \ZipArchive();
        if ($zip->open($zipPath, \ZipArchive::CREATE | \ZipArchive::OVERWRITE) !== TRUE) {
          throw new \RuntimeException('Cannot create zip archive.');
        }

        foreach (glob($sourceDir . '/*') as $file) {
          $zip->addFile($file, basename($file));
        }
        $zip->close();
      }

    }
    ```

=== "Drush command"

    ```php
    <?php

    declare(strict_types=1);

    namespace Drupal\my_module\Commands;

    use Drupal\my_module\Service\ProductArchiveService;
    use Drush\Attributes as CLI;
    use Drush\Commands\DrushCommands;

    final class ExportCommands extends DrushCommands {

      public function __construct(
        private readonly ProductArchiveService $archive,
      ) {
        parent::__construct();
      }

      #[CLI\Command(name: 'my-module:export:products')]
      #[CLI\Bootstrap(level: CLI\Bootstrap::FULL)]
      public function export(): void {
        $files = [
          'products.csv' => "sku,title\nW-001,Widget\n",
          'readme.txt' => 'Product export generated by Drush.',
        ];

        $path = $this->archive->exportToDirectory($files, 'public://exports');
        $this->io()->success("Export written to: {$path}");
      }

    }
    ```

## Symfony Filesystem directly

When stream wrappers are not needed (pure OS paths):

```php
<?php

declare(strict_types=1);

use Symfony\Component\Filesystem\Filesystem;
use Symfony\Component\Filesystem\Path;

$fs = new Filesystem();
$target = Path::join(sys_get_temp_dir(), 'drupal-sync', 'data.json');

if (!$fs->exists(dirname($target))) {
  $fs->mkdir(dirname($target));
}

$fs->dumpFile($target, json_encode(['synced' => TRUE], JSON_THROW_ON_ERROR));
```

!!! tip "Prefer file_system for URIs"
    Use `@file_system` whenever the path might be `public://` or `private://`. Use raw Symfony `Filesystem` only for system temp paths outside Drupal's file tree.
